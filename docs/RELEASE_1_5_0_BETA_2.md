# WorkBOXig v1.5.0 Beta 2

**Предварительный релиз для Windows.** Следующий этап после [Beta 1](https://github.com/FN1p/WorkBOXig/releases/tag/v1.5.0-beta.1). Все исправления Beta 1 включены.

## Что нового / What's new
- **Каналы обновлений — Stable / Beta.** В **Настройки → О программе → Обновления** появилась настройка **«Получать бета-обновления»** (или «Receive beta updates»). Выключена по умолчанию; выбор сохраняется после перезапуска.
- **Правильное сравнение версий.** Приложение различает `1.5.0-beta.1`, `1.5.0-beta.2`, `1.5.0-rc.1` и стабильную `1.5.0`: более старая сборка не предлагается в качестве обновления. Бета-канал получает также новые стабильные версии, когда они выходят.
- **GitHub Releases.** Стабильный канал проверяет `/releases/latest`, а бета-канал выбирает последнюю подходящую опубликованную версию по SemVer (черновики исключены).
- **Надёжность загрузки.** Контроль ожидаемого размера; проверка SHA-256 установщика при наличии контрольной суммы в метаданных GitHub. Портативный EXE не запускается как установщик.
- **Безопасная отмена.** Закрытие окна во время скачивания сначала отменяет загрузку, не уничтожая работающий поток; после завершения отмены элементы управления восстанавливаются.
- **Предупреждение о бета-версии** перед установкой и русские/английские подписи.

## Files
- `WorkBOXig_Setup.exe` — установщик Windows / Windows installer
- `WorkBOXig.exe` — портативная версия / Portable executable
- `SHA256SUMS.txt` — SHA-256 hashes for both executables

## Перед обновлением
1. Сделайте резервную копию пользовательских данных и закройте WorkBOXig.
2. При обновлении существующей установки используйте `WorkBOXig_Setup.exe`. Для отдельного теста без установки можно использовать `WorkBOXig.exe`.
3. Включите «Получать бета-обновления» в настройках, чтобы в будущем получать предварительные версии через встроенную проверку.
4. При проблемах сообщайте их в [PR #1](https://github.com/FN1p/WorkBOXig/pull/1) или GitHub Issues.

## Ограничения
- Сборка проходит автоматическое тестирование на Windows в GitHub Actions, но обновление поверх реальных пользовательских установок и восстановление старых резервных копий требуют дополнительной ручной проверки.
- Эта версия помечена **Pre-release**. Стабильный `v1.4.7` остаётся последней стабильной версией GitHub.
- Исходный код остаётся в тестовой ветке `workboxig-1-5-backup-hardening`; `main` не меняется.
