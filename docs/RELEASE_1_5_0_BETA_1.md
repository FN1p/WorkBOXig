# WorkBOXig 1.5.0 Beta 1

**Предварительная версия для тестирования Windows 10/11.** Не является стабильным обновлением.

## Что изменилось
- Исправлено кратковременное появление пустых системных окон при обновлении календаря.
- Обновлены окна создания и редактирования уроков и задач: можно перемещать и изменять размер, прокручивать содержимое, кнопки сохранения остаются видимыми.
- Исправлен выбор цвета занятий и очистка вложенных элементов интерфейса.
- Улучшена работа календаря с повторяющимися занятиями, чётными и нечётными неделями, переходом через полночь и сроками задач.
- Повышена надёжность резервного копирования и восстановления, добавлены сообщения об ошибках сохранения.
- Усилена проверка загрузок при обновлении и расширено покрытие автоматическими тестами.

## Скачать
- `WorkBOXig_Setup.exe` — Windows-установщик.
- `WorkBOXig.exe` — портативная версия без установщика.
- `SHA256SUMS.txt` — контрольные суммы файлов.

## Перед установкой
1. Создайте резервную копию данных в текущем WorkBOXig и, по возможности, скопируйте пользовательскую папку данных отдельно.
2. Закройте запущенную версию WorkBOXig.
3. Для первого теста предпочтительно проверить портативный EXE. Если используете установщик, учитывайте, что обновление с v1.4.7 на реальном ПК ещё проходит пользовательское тестирование.
4. Проверьте создание, редактирование и удаление занятий/задач, масштабирование Windows 100–150%, восстановление копии данных.

## Известные ограничения
- Ручная проверка обновления существующей установки и восстановления реальных старых резервных копий ещё необходима.
- Автоматический поиск обновлений использует GitHub latest и не предлагает предварительные релизы как стабильные.
- При обнаружении проблем сообщите их в GitHub Issues или [PR #1](https://github.com/FN1p/WorkBOXig/pull/1).

**Изменения содержатся в отдельной тестовой ветке** `workboxig-1-5-backup-hardening`. Стабильная ветка `main` не меняется.
