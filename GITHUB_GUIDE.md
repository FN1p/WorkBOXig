# 🚀 Инструкция по публикации WorkBOXig на GitHub и созданию Релиза

Данное руководство содержит пошаговый план по выгрузке репозитория на GitHub и публикации готовых установочных файлов (`.exe`) для пользователей.

---

## 📋 Шаг 1. Создание репозитория на GitHub

1. Откройте [GitHub](https://github.com) и войдите в свой аккаунт.
2. В правом верхнем углу нажмите **`+`** → **`New repository`** (или перейдите по ссылке [github.com/new](https://github.com/new)).
3. Заполните поля:
   - **Repository name:** `WorkBOXig`
   - **Description:** `Executive Productivity OS — Cyberpunk & Modern Desktop Workspace (PyQt6)`
   - **Visibility:** `Public` (или `Private` по желанию)
   - ⚠️ **КРИТИЧЕСКИ ВАЖНО:** **НЕ** ставьте галочки у:
     - ❌ *Add a README file*
     - ❌ *Add .gitignore*
     - ❌ *Choose a license*
     *(Все эти файлы уже созданы и настроены в локальном проекте).*
4. Нажмите зелёную кнопку **«Create repository»**.

---

## 🔗 Шаг 2. Привязка локального репозитория к GitHub

После создания страницы репозитория GitHub покажет ваш персональный URL (например, `https://github.com/ВАШ_ЛОГИН/WorkBOXig.git`).

Откройте терминал PowerShell в папке проекта (`C:\Projects\WorkBOXig`) и выполните:

```powershell
# 1. Привязываем удалённый репозиторий (замените ВАШ_ЛОГИН на ваш никнейм на GitHub)
git remote add origin https://github.com/ВАШ_ЛОГИН/WorkBOXig.git

# 2. Проверяем, что адрес привязался корректно
git remote -v
```

---

## ⬆️ Шаг 3. Выгрузка кода (Push)

Отправьте основную ветку на GitHub:

```powershell
git push -u origin main
```

> **Примечание:** Если GitHub попросит авторизацию, откроется окно браузера для быстрого подтверждения через аккаунт GitHub или ввод Personal Access Token.

После успешного выполнения страница репозитория на GitHub обновится: появится описание, скриншоты, бейджи и полный исходный код.

---

## 📦 Шаг 4. Публикация релиза с готовыми .exe (Releases)

Так как бинарные файлы `.exe` не хранятся в самом коде (они исключены через `.gitignore`, чтобы репозиторий оставался легковесным), их прикрепляют к **GitHub Releases**:

1. На странице вашего репозитория на GitHub справа найдите раздел **Releases** и нажмите **«Create a new release»** (или перейдите в `https://github.com/ВАШ_ЛОГИН/WorkBOXig/releases/new`).
2. Заполните данные релиза:
   - **Choose a tag:** введите `v1.0.0` и нажмите *Create new tag: v1.0.0 on publish*.
   - **Release title:** `WorkBOXig v1.0.0 — Executive Productivity OS & Cyberpunk Edition`
   - **Describe this release:** можно вставить краткое описание:
     ```markdown
     ### 🎉 Первый официальный релиз WorkBOXig v1.0.0!

     - ⚡ **Новая тема «Cyberpunk: Edgerunners»** с процедурным рендерингом неоновых HUD-кнопок, срезанными 45° углами и сигнальной штриховкой.
     - 📊 Интерактивный дашборд с аналитикой продуктивности и трекингом привычек.
     - 📅 Умный недельный/месячный календарь с динамической полоской реального времени.
     - 📝 Заметки с древовидной структурой блокнотов.
     - 🔔 Всплывающие уведомления в стиле Glassmorphism & Cyberpunk HUD.
     - 🔔 Полное отсутствие внешних тяжелых зависимостей и чистая работа с памятью.
     ```
3. **Прикрепите исполняемые файлы:**
   - В блок **«Attach binaries by dropping them here or selecting them»** перетащите файлы из папки `C:\Projects\WorkBOXig\dist\`:
     - 📥 `WorkBOXig_Setup.exe` (~82 МБ) — полноценный графический установщик с ярлыками.
     - 🚀 `WorkBOXig.exe` (~40 МБ) — портативная версия (не требует установки).
4. Нажмите **«Publish release»**.

Теперь любой пользователь сможет скачать и запустить программу в один клик!

## 🔄 Как обновлять проект в будущем

Когда вы внесете новые изменения в код:

```powershell
# 1. Посмотреть статус
git status

# 2. Добавить измененные файлы
git add .

# 3. Зафиксировать изменения с комментарием
git commit -m "feat: описание того, что было добавлено или исправлено"

# 4. Отправить изменения на GitHub
git push
```
